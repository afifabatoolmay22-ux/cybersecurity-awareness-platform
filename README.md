# Cybersecurity Awareness Platform

A web-based platform to educate users about phishing, digital arrest scams and malicious applications.

**Tech stack:** HTML, CSS, JavaScript, Python, Flask, SQLite

## How to run

1. Create a virtual environment: `python -m venv venv`
2. Activate it (Windows): `venv\Scripts\activate`
3. Install packages: `pip install -r requirements.txt`
4. Create a `.env` file containing `SECRET_KEY=your_random_key`
5. Start the app: `python app.py`
6. Open http://127.0.0.1:5000
